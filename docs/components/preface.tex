\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This project report is submitted as a part of the academic requirements for the \Course{} course. 
The objective of this project is to apply theoretical knowledge of microcontrollers, timers, 
interrupts, and digital interfacing to the design of a practical and functional embedded system.

The project focuses on the implementation of a digital clock using the AVR ATmega32 
microcontroller and seven-segment displays. Through this work, the author, \Authors{} gained 
hands-on experience in AVR architecture, timer configuration, interrupt handling, and display 
multiplexing techniques. The project was developed and tested using industry-standard tools: 
Microchip Studio and Proteus, which helped in understanding both software development and 
hardware-level simulation.

This report has been prepared with the intention of providing clear explanations of the design 
methodology, hardware and software implementation, and testing procedures. It is hoped that 
this document will be useful to students and readers who wish to understand the fundamentals of 
embedded system design using AVR microcontrollers.
